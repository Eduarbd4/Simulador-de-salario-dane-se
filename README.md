# Simulador DANE SE — Vendedores + Sub Gerentes

Projeto Next.js unificado.

## Fluxo
- Tela inicial: **VENDEDORES** ou **SUB GERENTES**.
- Vendedores: mantém as senhas atuais das lojas e o backend Supabase existente.
- Sub Gerentes: senha `SubGerente` (comparação sem diferenciar maiúsculas/minúsculas/acentos).
- Administrador: senha `administrador`, aceita pelas duas entradas e abre a administração existente das lojas.

## Senhas de Vendedores preservadas
- Flagship
- Brasília Shopping
- Lago Sul
- Mané
- ParkShopping

## Publicação
Substitua os arquivos do repositório atual por estes e faça push na branch conectada ao Vercel.
